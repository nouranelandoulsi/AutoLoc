# AutoLoc

Plateforme de gestion de location de véhicules multi-agences.

[À compléter avec les objectifs vus en Séance 1]

## Acteurs identifiés

- **Client** : consulte les véhicules disponibles, effectue des réservations, gère son compte
- **Agent d'agence** : gère les réservations, enregistre les départs/retours de véhicules
- **Responsable d'agence** : supervise l'agence, gère le parc de véhicules, consulte les statistiques
- **Administrateur** : gère les comptes utilisateurs, configure la plateforme, supervise toutes les agences
